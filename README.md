# 🛍️ Tienda Rooh - E-Commerce Multirrubro

Aplicación web moderna de comercio electrónico desarrollada con **React 18**, **Vite**, **TailwindCSS v4**, **Supabase** y checkout integrado de **Mercado Pago** y **WhatsApp**.

## 🚀 Inicio Rápido

### 1. Clonar e Instalar Dependencias
```bash
git clone https://github.com/Dariorod1/store-products.git
cd storeProducts
npm install
```

### 2. Configurar Variables de Entorno
Copia la plantilla de `.env.example` a `.env` y completa tus credenciales:
```bash
cp .env.example .env
```

### 3. Iniciar Servidor de Desarrollo
```bash
npm run dev
```
La aplicación estará disponible en `http://localhost:3000`.

### 4. Compilar para Producción
```bash
npm run build
```

---

## 🛠️ Tecnologías Principales
- **Frontend**: React 18, Vite 8, TailwindCSS v4, Lucide React, Canvas Confetti.
- **Backend & DB**: Supabase (PostgreSQL, Storage, RLS).
- **Pagos**: Mercado Pago Checkout Pro & Serverless API en Vercel.
- **Despliegue**: Vercel CI/CD.
